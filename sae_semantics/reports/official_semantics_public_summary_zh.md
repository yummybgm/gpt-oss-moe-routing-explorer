# Neuronpedia 官方 feature 语义数据：公开摘要

本项目针对 GPT-OSS-20B 的 SAE 层 3、7、11、15、19、23 建立了只读语义索引。完整 feature 宇宙为 786,432 个 `(sae_layer, feature_id)` 键。

- 官方已有解释：785,583
- 官方解释缺失：849
- 重复键：0
- 正确连接键：`(sae_layer, feature_id)`

完整 SQLite、原始批量下载对象和 API 响应保留在私有研究数据盘，不提交至公开 Git 仓库。公开仓库仅保留构建/验证脚本与覆盖率汇总。

`np_missing` 只表示官方来源没有解释；不能据此判断 feature 无语义或已经死亡。对缺失项的任何模型生成描述都必须单独标注来源和验证状态，不能冒充官方解释。
